# FlowWord

**停一下，看懂这一句**

FlowWord 是 Chrome / Edge 英语阅读助手：看视频时一键暂停看译文，读网页时划词翻译，收藏词句与来源，随时回看和复习。

当前版本：**0.9.2** · Chrome Manifest V3 · WXT + React + TypeScript

[功能手册](docs/FEATURES.md) · [安装与使用](INSTALL.md) · [开发说明](docs/DEVELOPMENT.md) · [文档导航](docs/README.md) · [更新记录](CHANGELOG.md)

## 0.9.2 更新

总设置与外层面板同步实际配色。固定划词框只锁定位置，重新框选后自动更新原文与译文，保留位置和尺寸。

## 0.9.1 配置与划词框优化

配置标签跟随主题，未选中仍清晰；总设置铺满剩余空间。划词框支持拖动标题、右下角缩放、固定位置记忆，以及「⋯ → 恢复默认位置与大小」。完整能力见[功能手册](docs/FEATURES.md)。

## 0.9 网站范围与主动查词

总设置支持一次启用所有普通网页、从打开的网站中逐个启停，并记住下次选择。视频学习配置保留；划词翻译独立配置字号、主题和“选中后自动翻译”（默认关闭）。

在快捷词本或完整词本打开查词，输入单词/词组并点击查找，即可获取释义、AI双语例句，并查找自己收藏中包含相同词组的真实原句。模型失败也保留本地原句结果。详见[改动说明](docs/changes/0.9.md)。

## 0.8 多种翻译接入

同一个悬浮设置框支持 Chat Completions、Responses 和本机 Codex CLI。CLI 通过项目内桥接复用本机 ChatGPT 登录，不需要 API Key；需单独启动桥接并导入连接文件，自动预译关闭。CLI 首次调用可能较慢，视频追求低延迟时建议使用云端 API。详见[安装说明](INSTALL.md)与[改动说明](docs/changes/0.8.md)。

## 0.7 新版界面与网页划词

统一暗绿阅读卡片、紧凑词本与单卡复习。已授权普通网页上选中不超过1500字符的英文后出现工具条，点击翻译才发送所选文本及必要短语境；支持固定、拖动、收藏与来源回跳。密码框、输入区、编辑器和插件自身的选区不参与。

网页收藏使用明确的网页来源，不保存虚构视频时间；可按来源搜索、导出并进入本地复习。数据库升级v3、备份v4，兼容导入v1–v3；升级前请从0.6.1导出备份，旧版本不能直接打开升级后的数据库。

## 0.6.1 更新

清理词本侧栏说明小字，封面开关收进分类与排序；完整和悬浮词本均支持搜索视频标题与多个关键词。网页划词翻译在0.7接入，设计依据见[方案](docs/plans/web-selection-translation.md)。

## 0.6 新增

可见视频自动加载封面；词卡显示来源与时间，支持列表/卡片、分页搜索、批量分类、删除撤销和按视频导出。新增学习状态及每日轻量复习，先看英文与原句，再揭晓中文并评分；复习及来源重听不请求模型。

翻译支持分项重试、共享请求取消及缓存异常降级。词条与视频归档在同一事务保存，完整备份升级到 v3，兼容导入 v1/v2。升级前请导出旧备份，迁移后如回退旧扩展，旧库不会包含新版本新增数据。

## 可以做什么

| 功能 | 操作与效果 |
| --- | --- |
| 暂停与恢复 | 左键点击球暂停并捕获字幕，再次点击继续播放并关框 |
| 整句翻译与表达解释 | 整句和表达并行准备，成功结果先显示，专业词、搭配和地道表达优先 |
| 上下文阅读 | 小号英文上文与下文放在当前句两侧，点击邻句展开中文 |
| 句子重听与字幕跟随 | 重听当前字幕范围，或播放中跟随字幕更新面板 |
| 语境收藏 | 收藏单词、词组、整句，保留视频时间或网页原文、来源和当时释义 |
| 快捷词本与完整档案 | 悬浮框内搜索最近收藏，完整词本支持视频/网页来源筛选、分类、标签及备份 |
| 自定义外观 | 默认暗绿色，支持多主题、字号、独立框尺寸、球颜色与自由定位 |
| 框内模型设置 | 默认预填 DeepSeek，可修改兼容接口；配置时保留已有密钥 |

默认快捷键：`Alt+Shift+P` 暂停/恢复，`Alt+Shift+R` 重听当前字幕，可在浏览器扩展快捷键页面改绑。

## 从源码运行

需要满足 `package.json` 中的 Node.js 版本要求，推荐 Node.js 24。以下命令在项目根目录执行。

```powershell
npm ci                # 按锁定版本安装依赖
npm run build         # 生成生产扩展
```

在 `chrome://extensions` 或 `edge://extensions` 开启开发者模式，选择“加载已解压的扩展程序”，加载 **`.output/chrome-mv3`**。

打开有英文字幕的受支持视频页，在工具栏 FlowWord 中开启悬浮球。其他网站需要先在工具栏中为当前站点单独授权并刷新。详细配置见 [安装说明](INSTALL.md)。

已安装用户应在**原加载路径**重新加载，避免因扩展 ID 改变而看不到原有数据。更换路径前先导出词本备份。

## 翻译配置与数据

- 右键悬浮球 → 模型设置，在原框内填写接口、模型和 API Key，授权并保存
- 默认预填 DeepSeek，联网初始关闭；已有服务选择保留，不自动切换供应商
- 视频云端收到当前字幕及最多两句邻近字幕；网页翻译只发选区与最多一条短语境，均不上传来源网址；费用和数据处理由供应商决定
- MyMemory 是可主动选择的整句参考服务，不提供模型语境分析
- 密钥保存在扩展来源的 IndexedDB，不写入源码、`storage.local` 或词本备份，不回填到输入框
- 视频学习档案、收藏和设置保存在本机；通过 JSON 导出/导入备份词本
- 自动封面取决于来源图片是否可用；轻量复习使用本地收藏，评分不调用模型

请勿把 API Key、个人词本备份或浏览器资料提交到仓库。源码使用浏览器设置配置密钥，不需要 `.env`。

## 速度与兼容边界

可选播放预译和词组预解析，两类结果均有持久缓存。首次请求、新字幕、跳转、预算用尽或网络异常仍可能等待，不保证零延迟。

YouTube 主要适配普通 `watch` 页面；其他网站主要支持顶层可见 HTML5 主视频和已启用的英文原生字幕。自绘播放器字幕、跨域 iframe、无字幕视频需要专门适配。YouTube 直播、Shorts 和系统播放器不在当前支持范围内。

原生字幕重听按 `cue.end` 结束；页面 DOM 字幕通过实际字幕转换判断，自动字幕无标点时不能保证完整语义句末。模型译文也仍需核对。

## 开发、测试与打包

```powershell
npm run dev               # 启动开发构建
npm run typecheck         # 检查类型
npm test                  # 运行单元测试
npm run browser:install   # 首次准备项目内测试浏览器
npm run verify            # 类型、单测、生产构建和浏览器回归
npm run zip               # 生成 .output 下的扩展 ZIP
```

本版通过303项单元测试和112项浏览器场景；0.6.1已保留为GitHub标签v0.6.1。浏览器场景主要使用隔离资料、本地字幕夹具和模拟云响应，不能据此宣称所有真实网站、真实模型速度和系统快捷键都已验证。详见 [测试报告](TEST_REPORT.md)。

`npm run package` 用于维护者整理本机发布目录，并复制验证证据；缺失的历史证据会在 evidence-manifest.json 中明确标记，不冒充当前通过记录。普通源码安装使用 `build`，ZIP 分发使用 `zip`。

## 目录结构

```text
entrypoints/      扩展后台、视频内容脚本和页面入口
src/
  adapters/       视频与字幕适配
  core/           字幕整理、交互和重听控制
  services/       翻译请求、缓存调度和预译
  storage/        本地设置、词本和视频归档
  ui/             悬浮界面与复用组件
public/           图标等静态资源
tests/            单元测试及本地测试夹具
scripts/          浏览器回归、构建辅助与打包脚本
docs/             开发文档、审查结果和历史修改说明
INSTALL.md        安装与升级说明
TEST_REPORT.md    发布验证与未覆盖范围
CHANGELOG.md      版本更新记录
```

`node_modules`、`.cache`、`.wxt`、`.output`、`test-results` 和 `release` 是本机依赖或生成目录，已从 Git 排除。ZIP 可通过 GitHub Releases 单独分发。
