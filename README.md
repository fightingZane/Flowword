# FlowWord 0.2.0

支持 Chrome / Edge 的 YouTube 普通视频页。

- 左键：暂停、读取当前字幕、显示中文参考翻译与优先学习表达
- 再次左键：继续播放并关闭框，加载过程中也可操作
- 右键：配置字体、翻译框主题和宽度、球颜色、风格与透明度
- 加入单词本：词、短语、句子分类；词性、多个考点、自定义标签；组合筛选、编辑、删除与 JSON 导出

联网默认关闭。右键开启“联网翻译 · MyMemory”后，字幕和查询表达会发往该服务；服务可能长期保存并交由第三方机译处理。不发送视频地址或浏览历史，请勿用于敏感内容。匿名服务有额度和准确性限制。

排序是本地难度参考，不是个人不会概率。单词释义未经语境消歧；八词提供自编中文多义参考与 Cambridge 核验链接，其他词由在线服务提供通用参考义。没有个人词汇模型或完整词典。

设置保存在扩展 storage，词本在 IndexedDB。卸载前请导出备份，当前不支持导入、云同步。仅支持 watch 页，需启用 English 字幕；广告、直播、Shorts和系统悬浮窗不支持。字幕缓存12秒，拼接不保证完整句。播放器容器全屏支持。

安装升级见 [INSTALL.md](INSTALL.md)，验证见 [TEST_REPORT.md](TEST_REPORT.md)。开发执行 npm ci、npm run verify；打包执行 npm run zip、npm run package。
