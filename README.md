# FlowWord 0.5.1

英文视频学习扩展，Chrome / Edge。升级见 [安装说明](INSTALL.md)。

- 左键暂停并理解字幕，再次左键继续播放并关框
- 悬浮球默认自由放置，也可选边缘吸附；收藏后显示已加入，仍能追加新语境
- 词本左侧视频资料栏、右侧紧凑词卡，支持来源跳转和主动加载视频封面
- 收藏整句固定在当前原句旁；表达也可收藏
- 拖动标题移动框，右下角调整宽高；字号独立，内部滚动
- 悬浮框新增森林、暮紫、落日、玫瑰、墨金等主题；词本八套独立主题
- Alt+Shift+P 暂停/恢复，Alt+Shift+R 重听当前字幕范围，浏览器快捷键页可改绑
- 点击“字幕跟随”进入歌词式阅读：当前句突出，上下句缩小，随真实字幕推进
- 学习档案保存视频、时间戳、原句、收藏表达及当时语境义；按视频筛选与时间排序
- 词本支持备份JSON导入/导出，旧词本自动迁移到新归档关联

## 翻译服务
右键悬浮球 → 云端模型与快捷键设置，在原框内填写并保存；默认预填DeepSeek接口和deepseek-flash，已有服务选择保留。密钥仅在扩展来源的嵌入框输入并存在扩展来源IndexedDB，不放网页配置框、源码或词本备份。
云端收到当前字幕及最多两条邻近文本，不发送视频URL；模型供应商的数据政策和费用由用户选择服务时确认。没有配置Key时，只能完成模拟协议验证，不能声称实际模型已可用。

整句和专业词、地道词组释义并行请求，先完成的先显示，两类结果均持久缓存。DeepSeek官方接口自动关闭思考模式并控制输出长度，其他服务保持原兼容参数。模型可能误译，中文/格式/原文跨度校验不能证明语义一定正确。
旧版MyMemory保留为用户明确选择的整句参考服务，不再脱离语境逐词查询；拒绝纯数字、回显和HTML垃圾结果，不自动切换服务。

## 快速呈现与费用
可单独允许播放中预译已出现的当前字幕及轨道已加载邻句，每次最多2句、每标签页浏览器会话最多20句预处理尝试。旧开关只预译整句；新增“提前准备词组释义”默认关闭，主动勾选后每个新句最多增加一次模型调用。直接点击和主动字幕跟随不属于该预译额度限制。
希望点开两者都齐时，同时开启播放预译和提前词组释义并保存，回视频播放让缓存准备。未完成、新位置、预算用尽或网络异常仍可能等待。
译文缓存持久保存7天、最多1000条，可清除。缓存命中可快速查看；初次启用、新字幕、跳转或网络异常仍可能等待，不保证零延迟。
DOM字幕没有未来句；只有真实字幕轨道可提供已加载下句。未准备的邻句译文明确提示。

## 跨网站边界
YouTube仍默认适配普通watch页。其他站在浏览器图标中点击“在此网站启用”后单独授权并刷新，只支持顶层可见主HTML5视频及已启用的英文原生字幕轨道。
无字幕、自绘字幕、跨域iframe、多个无法确认的主视频需要专门适配，不能宣称所有网站都兼容。YouTube广告、直播、Shorts、系统播放器不支持；通用站广告无法可靠判断，请在正片中使用。通用链接时间跳转依网站支持，媒体签名或Blob变化可能被记录为新视频身份。

## 本地数据
旧flowword-wordbook数据库保持version1，新归档用独立数据库，不原地升版本。旧版回滚可读原词本，新归档信息需先导出。新路径加载可能产生不同扩展ID，使用导出/导入恢复；优先在原路径重新加载。
预译和云端服务默认受联网总开关控制；撤销站点权限停止该站采样。关闭叉号/Escape不自动恢复视频。

开发：npm ci、npm run verify。打包：npm run zip、npm run package。详见 [测试报告](TEST_REPORT.md)、[架构](ARCHITECTURE.md)、[修改说明](CHANGE_DETAILS_0.3.md)。

## 0.5 悬浮面板
配置与快捷词本直接在视频悬浮框内打开，不自动增加标签页
快捷词本搜索原文、词形和译文，按最近时间展示20条；打开完整单词本才进入完整网页
默认暗绿色，保留已有自选主题；已有服务与密钥保留，密钥不回填输入框，留空保存沿用
上文在当前句上方、下文在当前句下方，默认小号英文，点击才展开或请求中文
