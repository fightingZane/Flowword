## 使用边界

CLI采用ChatGPT登录时使用订阅访问；API Key登录使用API计费，两者不同。桥接仅接受ChatGPT登录，不会在失败后偷偷切换计费方式。额度、可用模型和账户限制由官方服务决定

CLI有进程启动与推理等待，首次结果可能比专用翻译API慢。需要视频快速响应时，优先选择云端API并按需开启预译；重复文本可命中现有缓存

官方依据：[认证](https://learn.chatgpt.com/docs/auth)、[非交互调用](https://learn.chatgpt.com/docs/non-interactive-mode)、[Responses迁移](https://developers.openai.com/api/docs/guides/migrate-to-responses)
