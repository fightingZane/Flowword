# FlowWord 0.3 升级方案 · 已批准开发

日期：2026-10-14。用户已选择可配置云端模型 API，并接受少量调用费用，随后明确指令“开始直接开发”。本文件保留批准方案；最终实现与验证以README和TEST_REPORT为准。

## 1. 目标与价值

把字幕查看器升级为以句子和视频为单位的英语学习工具：快速看懂当前句、理解地道表达、重听、收藏并溯源。核心用户是边看英文视频边学习的个人用户。成功标准是交互不打断观看、引用可追溯、译文优先呈现、收藏不丢失。

## 2. 功能与边界

P0：当前句与表达收藏、自由调整框宽高、独立字体、整句优先返回、上下文模型释义、快捷键暂停恢复和重听、视频来源记录、存量数据迁移。

P1：可读取字幕的通用HTML5视频、独立词本主题、八套主题、上下文字幕流水视图、视频分组及时间轴、播放中有限预译。

P2：新增专用网站适配器、字幕文件导入、个人词汇水平、语音转写。烧录字幕OCR、任意网站无字幕转写、手机及系统播放器本轮不包含。

输入为字幕文本、时间轴、已知上下文和用户配置。模型输出为整句中文、语境表达、当前句词性与释义、专业/地道表达说明。不存在字幕时显示能力提示；网络或模型失败仍可操作视频；输出结构不合法不能冒充成功。

## 3. 交互设计

句子旁固定“收藏整句”，收藏表达和整句使用相同分类表单。面板拖动移动，边缘或角落拖动宽高，设置中可输入数值与重置。字体仅影响内部排版，外框尺寸不随文字扩张；长内容内部滚动，最小尺寸和屏幕边界约束。

阅读区提供上句、当前句、下句：当前句大字高对比，上下句小字；自然播放时随字幕推进，暂停后固定。来源是字幕分段，不凭空补造下句。仅有DOM字幕时，下句未观测则留空。详细语境表达放在可展开区域。

八套候选主题：纸页、森林、午夜、海盐、暮紫、落日、玫瑰、墨金。球、字幕框、词本分别可选主题，可选择联动；颜色以阅读对比度为先。

## 4. 技术知识

用户必须理解：网站访问授权、模型请求会发送字幕、预译额外费用、模型可能误译、API密钥本地配置。

大致了解：字幕轨道与页面字幕的区别、缓存命中、上下文不足、重复播放需要句子边界。

AI负责：网站适配、请求队列与缓存、模型结构输出校验、状态机、数据库迁移、主题与测试。

## 5. 原理与可行性

现有延迟原因已由代码确认：后台串行翻译整句和多个词，全部结束才返回。改为整句优先独立发布，表达解析不阻塞整句。持久缓存按字幕、上下文、模型和提示版本区分，避免跨语境复用词义。

点击即见译文依靠已准备字幕、播放中预译和缓存：完整轨道可预译当前位置附近少量句子；DOM字幕只能在实际出现后开始。首次遇到字幕、首次启用、网速差、跳转陌生位置仍可能等待，不能保证所有情况零延迟。

完整字幕优先使用原生textTracks；页面自绘字幕需要站点适配器。无可读取字幕的视频不能只靠播放器接口完成翻译。多视频、跨域iframe、直播、广告、DRM和页面变动都需要能力判断，不宣称任意网站完全兼容。

重听完整轨道句子采用可靠起止时间，播放一次到句尾暂停；DOM片段只重听已观测片段，清楚提示边界不完整。切视频、跳转、手动播放和广告变化要退出旧重听状态。

## 6. 技术方案与架构

方案A：免费翻译服务。配置简单，但现有截图已出现垃圾词译和语境错译，无法承担详细语境学习的主服务。

方案B：可配置云端模型API。推荐；无需安装本地模型，可根据完整句子解释表达，代价是网络、费用和服务商数据处理。优先适配常见兼容接口，配置Endpoint、模型名、Key；真实可用性以用户服务配置验收，不预设任何厂商必然兼容。

方案C：本地模型。隐私和离线可控，但安装和硬件要求较高，速度依电脑而变，保留后续接口。

沿用WXT、React、TypeScript与MV3，不新增无必要后端。模块划分为Video/Subtitle Adapter、Sentence Timeline、Playback Controller、Translation Scheduler、Provider、Learning Archive、Theme与Resizable UI。

模型输出需绑定来源句ID，表达必须能定位到原文跨度，解释当前语境义而非堆砌所有默认义；专业词和地道表达优先，过滤基础词和不可信纯数字结果。模型结构校验只能减少错误，不能证明事实正确。

数据模型：videos保存站点、规范化URL、标题、稳定标识；captures保存videoId、起止时间、原句、译文与服务来源；entries保存词/短语/句子及用户分类；occurrences保存entryId、captureId和语境义。同一个词在不同视频保留不同语境，通过关系关联，不覆盖。

## 7. 分阶段执行

A：交互与归档。自由宽高、独立字体、收藏整句入口、主题、快捷键、视频/时间轴记录、数据库迁移。交付本地可用并且旧数据不丢失的版本。

B：翻译升级。可配置云端API、整句先返回、语境表达结构、限量预译与缓存。先用模拟服务验证异步流程，再用用户本地配置做真实服务验收；没有Key时不得报告真实模型成功。

C：跨网站与上下文。通用原生字幕适配、按站授权、歌词式时间轴、特定网站能力测试。交付明确的兼容矩阵，而不是“所有网站通过”的空泛结论。

## 8. 测试与验收

- 收藏按钮无需滚动到底即可访问；单词、短语、整句均能保存与分类
- 相同外框大小下字体从14调到24，宽高保持一致，内容可滚动且操作按钮可见
- 鼠标和快捷键暂停/恢复一致；可修改快捷键，冲突显示；重听不操作其他视频
- 同词在两个视频收藏，各自语境保留；按视频分组和时间排序，来源链接可定位或明确不支持跳转
- 旧0.2词本迁移后数量、标签、来源不丢失，失败可恢复；JSON导出可验证
- 已准备译文点击立即呈现，记录缓存命中率和首次译文延迟P50/P95，不能用模拟服务速度冒充实际性能
- 整句到达即显示，慢表达分析不延迟它；旧结果、跳视频、取消、超时不覆盖新句
- 标准HTML5轨道至少覆盖两个不同来源测试页；主视频、iframe、无字幕与无权限各有明确结果
- 主题在窄屏/全屏和词本中检查对比度、键盘可达性与溢出

## 9. 部署、成本与维护

仍为本地浏览器扩展。API Key仅在扩展配置中输入，不发聊天、不进入源码、导出或日志；扩展本地存储不是硬件安全保险库，提供清除密钥功能。网络请求在扩展后台执行，对配置主机单独授权，不给普通网页密钥。

默认按点击请求；预译单独开启，限制邻近句数、队列与会话预算，提供清除缓存。不能在未选模型前承诺金额；记录token用量（服务返回时）和调用数。模型失败不自动切到其他服务上传字幕。

升级前导出，保留0.2回滚包和本地Git版本；迁移兼容旧数据库，回滚前备份新版数据。日常不采集与学习无关的浏览记录。

## 10. 风险与替代

主要风险是字幕不可读、云模型延迟/幻觉、自动预译费用、DOM句尾不可靠、跨站权限、数据迁移。替代路径依次是专用站点适配、明确片段边界、用户手动纠正、关闭预译、保留原文和旧记录。

未确定项：用户实际API服务及模型、优先验收的网站、是否提供完整字幕轨道。配置界面可先完成，不以未知密钥阻塞离线开发。
