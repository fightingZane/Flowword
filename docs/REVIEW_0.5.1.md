## 优先修复

| 级别 | 问题 | 证据与边界 |
| --- | --- | --- |
| P1 | 过期翻译仍占用请求槽位，可能继续产生费用 | learning.ts 取消展示但未把取消信号传至后台请求，真实费用未测量 |

| P1 | 备份导入可能部分写入或覆盖并发编辑 | 词条恢复早于归档完整校验，恢复时间另一次整条 put 没有版本校验 |
| P2 | 预译失败、跳过或缓存命中也消耗预算 | 发送前标记尝试，后台预留额度，没有成功状态回收 |
