# FlowWord 功能手册

> 当前功能基线：0.9.2 · 浏览器内的视频学习、网页阅读、词句收藏与本地复习
>
> 本页汇总已实现功能和使用边界，安装步骤见 [安装与配置](../INSTALL.md)

## 从哪里开始

| 想做什么 | 入口 | 结果 |
| --- | --- | --- |
| 暂停视频看翻译 | 左键悬浮球 | 暂停主视频、捕获当前英文字幕、展示翻译与重点表达 |
| 继续观看 | 再次左键悬浮球，或「继续观看」 | 恢复视频并收起翻译框 |
| 调整功能与外观 | 右键悬浮球 → 配置 | 总设置、视频学习、划词翻译三个分类 |
| 管理启用的网站 | 配置 → 总设置，或工具栏 FlowWord → 总设置 | 全站启用、逐站启停、记住网站选择 |
| 翻译网页文字 | 在已启用网站选中英文 → 翻译 | 原地查看译文和表达，可固定、拖动、复制、收藏 |
| 设置翻译服务 | 配置 → 模型设置 | 云端 API、Codex CLI、MyMemory 或关闭联网 |
| 找最近收藏 | 翻译框 → 单词本 | 先打开悬浮词本，支持搜索和本地复习 |
| 整理全部收藏 | 悬浮词本 → 打开完整词本 | 来源分组、多维筛选、分类编辑、批量操作和备份 |
| 主动查单词或词组 | 悬浮词本 → 查单词与词组，或完整词本 → 查词 | 中文释义、AI 双语例句、自己收藏中的真实原句 |
| 改键盘操作 | 模型与快捷键设置 → 修改键盘快捷键 | 打开浏览器扩展快捷键页面改绑 |

## 视频学习

| 已实现 | 使用方式与边界 |
| --- | --- |
| 一键暂停与恢复 | 球的左键在查看、继续之间切换，右键打开配置 |
| 整句中文翻译 | 根据当前字幕请求译文，整句与表达分别准备，支持失败重试 |
| 语境表达解释 | 优先专业词、搭配和地道表达，解释结合原句；可展开更多表达 |
| 上下文阅读 | 当前句突出，上下邻句缩小显示；邻句默认英文，点击才展开中文 |
| 字幕跟随 | 播放中更新当前句与上下文；未捕获的未来字幕不凭空补全 |
| 重听当前句 | 跳回已知句首，按字幕范围播放；原生轨道和页面字幕的结束判断不同 |
| 字幕时间微调 | 捕获偏移时可手动调整选中的字幕时刻 |
| 复制与收藏 | 可收藏单词、词组和整句，并保留原句、来源和视频时间 |
| 预译与缓存 | 云端可选播放预译、词组预解析，准备完成的内容可更快打开 |

默认快捷键：**Alt+Shift+P** 暂停／恢复，**Alt+Shift+R** 重听当前字幕

快捷键冲突时需在浏览器改绑；浏览器是否允许当前组合，取决于系统和其他扩展

## 网页阅读与网站范围

- **手动划词**：选中不超过 1500 字符的可选择英文，点击翻译才请求服务
- **可选自动翻译**：在「划词翻译」开启「选中后自动翻译」，默认关闭，开启后真实选区操作可能消耗模型额度
- **阅读卡片**：拖动标题自由移动，拖右下角调整宽高；固定只锁定位置，已打开的固定翻译框会随真实新框选更新译文；位置与尺寸保存在本机，可在「⋯」中恢复默认位置与大小；也支持复制、收藏，未固定卡片可点击外部或按 Esc 关闭
- **网页来源**：保存原文与真实网页，不附加虚构视频时间；支持回到原文
- **独立配置**：划词有自己的启用开关、字号与主题，不会因为调划词字号而改变视频外观
- **网站管理**：可逐站授权，或明确批准「在所有普通网页启用」，再设置网站例外
- **记住选择**：同一来源的网站共用启停选择，不同协议、子域分别管理；关闭网站后停止该站字幕与选区采样

密码框、输入区、编辑器和插件自身不参与划词；不会为了翻译而上传整页正文

## 外观与布局

| 对象 | 可调整内容 |
| --- | --- |
| 视频翻译框 | 字号、独立宽高、拖动位置、主题；字号与框尺寸分开设置 |
| 悬浮球 | 颜色、磨砂／纯色／线框风格、不透明度、自由放置或边缘吸附 |
| 划词卡片 | 独立字号与主题、固定与拖动 |
| 完整词本 | 全页主题、列表／卡片切换、可收起来源侧栏、窄屏布局 |
| 阅读主题 | 跟随系统、纸页、午夜、米纸、海盐、森林、暮紫、落日、玫瑰、墨金 |
| 词本八套主题 | 薄雾森林、午夜墨绿、焦糖奶茶、深海蓝调、紫藤花园、玫瑰信笺、落日橘光、薄荷冰川 |

默认暗绿阅读风格，长内容使用随主题配色的滚动区域；窗口大小仍受网页可视范围约束

## 词本、来源与复习

| 已实现 | 能做什么 |
| --- | --- |
| 三类收藏 | 单词、词组、整句一起保存，按词汇类型、考点／考试、自定义标签分类 |
| 多来源归档 | 同一词可保留不同视频、网页、时间与原句，不用新释义覆盖其他来源旧义 |
| 来源回看 | 显示来源简称；视频保留时间，网页显示回到原文；来源内可按时间顺序整理 |
| 搜索与筛选 | 搜索原文、译文、标签和来源标题，多关键词搜索；筛选类型、来源、分类及学习状态 |
| 学习状态 | 新收藏、学习中、已掌握，可手动修改 |
| 语境释义编辑 | 单独修改某一来源的释义，保留其他语境的意思 |
| 批量整理 | 批量分类、修改状态、删除与撤销删除；撤销在有效期内且不覆盖后来重新收藏的数据 |
| 来源封面 | 可见视频尝试加载封面，失败显示占位；可关闭，不为无封面来源伪造图片 |
| 悬浮词本 | 最近更新优先、搜索、每页 20 条，可打开完整词本 |
| 完整词本 | 每页 40 条，列表／卡片持久保存，按视频或网页来源分组 |
| 本地复习 | 每轮最多 10 个词句，先看英文与原句，揭晓中文后评分，不调用模型 |

复习评分规则：忘记的词本轮稍后再出现一次，次日再复习；不确定的词次日复习；记住的词按 **1／3／7／14／30 天**安排，最长维持 30 天。手动标为已掌握后退出到期队列

来源重听不调用模型；准确定位仍取决于网站权限、页面是否变化、视频和字幕是否能匹配

## 主动查词与例句

输入单词或词组后，**点击查找**才请求模型并自动生成 1–3 条双语例句，输入每个字符不会触发调用

- 中文释义与「AI 生成例句」分区显示，可复制，不把生成内容伪装成真实网页或视频收藏
- 同时检索全部收藏语境中的真实原句，最多展示 20 条并标明命中总数
- 原句按完整词／词组边界匹配，避免 `stand` 误命中 `understand`
- 本地检索不调用模型，模型失败时仍可查看收藏原句
- 目前不做词形还原、模糊联想或语义近似检索

**例句生成链路已实现，但真实模型的释义准确性、造句质量与响应速度仍需实际使用验收**

## 翻译服务与费用

| 接入方式 | 配置与适用范围 |
| --- | --- |
| 云端 API | 可选 Chat Completions 或 Responses；提供 DeepSeek／OpenAI 预设，填入实际可用的接口、模型和 Key |
| 本机 Codex CLI | 先使用 ChatGPT 登录 CLI，运行项目桥接，导入连接文件；不要求另填 API Key |
| MyMemory | 可主动选择的整句参考机译，不提供模型语境解释或 AI 造句 |
| 关闭联网 | 不发起新的翻译与预译；本地词本、原句检索、复习和备份仍可使用 |

云端默认仅预填 DeepSeek，初始联网关闭；升级保留原服务选择，不自动替换已有配置

云端「测试连接」会发起模型请求；CLI「测试连接」只检查本机桥接与 ChatGPT 登录，「试译一句」才实际调用 CLI。保存 CLI 配置不发起试译，CLI 自动预译始终关闭

云端预译可准备已出现字幕及已加载邻句，每次最多两句、每标签会话最多二十句；词组预解析可能额外调用。首次、新句、跳转、预算用尽或网络失败仍会等待，**不保证点开即有译文或零延迟**

CLI 需要本机桥接持续运行，首次启动与推理可能较慢，账户额度与可用模型由所用服务决定。使用说明见 [CLI 配置](../INSTALL.md#本机-codex-cli可选)

## 本地数据与备份

- 收藏、学习来源、复习状态和设置保存在本机，没有云端账户同步
- 完整词本可导出全部备份，也可只导出当前视频或网页；支持 JSON 导入恢复
- 当前导出 **v4** 备份，兼容导入旧 **v1–v3**；旧扩展不能直接导入 v4 或打开升级后的数据库
- API Key 与 CLI 连接令牌仅保存在扩展来源数据库，不回填输入框，不写入词本导出
- 改接口需要重新确认凭据；清除密钥同时关闭联网
- 云端视频翻译发送当前字幕和有限邻句，网页翻译发送选区与必要短语境，不上传来源网址；第三方文本处理以所选服务为准
- 自动封面会请求来源图片服务，关闭封面可停止后续装载；图片可能失效

升级、换路径或卸载前先导出完整备份；回滚需要升级前备份，保留原扩展加载路径可避免扩展 ID 改变带来的数据不可见

## 当前限制与尚未实现

| 用户目标 | 当前状态 |
| --- | --- |
| 所有网站视频都适用 | **部分支持**：YouTube 普通 watch 页面；其他站主要为顶层可见 HTML5 主视频与已启用英文原生字幕 |
| 没字幕也能翻译视频 | **未实现**：没有通用实时听写、OCR 或系统音频识别 |
| 直播、Shorts、跨域 iframe、桌面播放器 | **不在当前承诺范围**，需要专门适配 |
| 任意图片、扫描 PDF、浏览器内部页都能划词 | **不支持**：依赖普通网页上可选择的文字及浏览器授权 |
| 翻译永远准确、词义足够详尽 | **不能保证**：模型结合语境，但仍可能误译、遗漏或解释不足；MyMemory 只有参考机译 |
| 按本人不会的概率精确排序 | **未实现个人能力预测**：当前优先专业词、搭配、地道表达，难度为参考 |
| 歌词式上下文效果 | **已实现当前句突出、邻句缩小与跟随更新**，不承诺音乐播放器式连续逐字动画 |
| 任何时候都能精确回原句 | **条件支持**：网页改版、字幕不完整、权限缺失时可能仅打开来源页面 |
| 秒出全部译文与释义 | **不保证**：缓存和预译只能减少等待，不能消除首次请求或服务延迟 |
| 跨设备同步、自动云备份 | **未实现**，当前通过本地 JSON 备份迁移 |

验证以隔离浏览器、本地字幕夹具和模拟模型响应为主，不能据此宣称全部真实网站兼容、真实账号额度可用或模型质量已验收。具体记录见 [测试报告](../TEST_REPORT.md)
