# FlowWord 第二版交互稿

`flowword-v2.html` 是可预览的界面设计，包含视频阅读、网页划词、快捷词本、完整词本、复习和框内设置

本文件描述独立演示稿，不调用模型、不写入真实收藏。正式插件已在0.7按此设计接入，实际实现与验证见docs/changes/0.7.md

## 设计决定

- 默认深墨绿、薄荷绿强调色，当前英文和中文译文连续显示
- 上下文使用紧凑英文，点击展开中文，不插入占位说明
- 常用动作直接显示，低频设置进入一层展开区
- 词本默认列表，来源标题/时间直接可见，保留卡片切换
- 网页划词先显示工具条，点击展开翻译卡，未授权自动请求
- 演示中的网页来源分组属于后续规划，正式0.6.1目前仍以视频收藏为主

## 原型可体验范围

可操作：页面切换、邻句中英展开、收藏状态、划词卡片关闭/再开/固定、搜索/类型及状态筛选、列表/卡片、词义编辑、条目选择/删除/撤销、本地复习/忘记补一次、示例主题与字号

仅示意入口：真实播放/句末暂停、复制剪贴板、导入导出、真实批量分类、全部高级筛选、站点授权、Key存储、真实模型连接和浏览器快捷键

原型收藏按钮只演示已加入状态，不把任意选区真正存入数据层。正式开发时不得以原型回调替换现有真实功能

## 后续实现顺序

1. 在现有组件上统一视觉变量、排版和按钮层级，保留数据与播放控制器
2. 接入新视频面板、配置、快捷词本、完整词本和复习布局，逐项核对上述功能表
3. 独立开发网页选区模块和通用来源迁移，不与视频UI改造混成一次不可回滚的大改
4. 全量回归、真实浏览器体验、对照旧版功能验收后发布
